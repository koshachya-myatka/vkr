0. Извлеките из архива все содержимое (папка "vkr")

1. Запустите Docker Desktop

2. Перейдите в папку "vkr", запустите из нее консоль 
 
3. Введите команду ниже
  docker compose up --build -d

4. Дождитесь запуска всех контейнеров системы

5. Введите в браузере адрес ниже
  http://localhost:5173/login

6. Войдите в нужный по роли профиль
Данные для входа:
  Роль - администратор  
  Логин: admin  
  Пароль: 123
  
  Роль - руководство  
  Логин: manager  
  Пароль: 123
  
  Роль - лаборатория  
  Логин: lab  
  Пароль: 123
  
  Роль - производство  
  Логин: prod  
  Пароль: 123 

* Данные о партиях появляются в процессе работы контейнеров, 
первые несколько секунд список партий может быть пустым

7. Для удаления контейнеров и volume введите в консоли команду ниже
  docker compose down -v
