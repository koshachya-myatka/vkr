@startuml
skinparam actorStyle Hollow
title Просмотр информации о партии металла и формирование отчёта
actor "Пользователь" as User
skinparam defaultFontSize 24
skinparam title {
  fontSize 18
}
skinparam sequence {
  ParticipantFontSize 24
}

participant "Frontend" as Frontend
participant "Backend" as Backend
participant "JWT Filter" as JWT
database "PostgreSQL" as DB
participant "Report Service" as PDF

== Авторизация ==

User -> Frontend : Ввод логина и пароля
activate Frontend

Frontend -> Backend : POST /api/auth/login
activate Backend

Backend -> JWT : Проверка\nпользователя
activate JWT

JWT --> Backend : JWT-токен
deactivate JWT

Backend --> Frontend : Access token
deactivate Backend

Frontend --> User : Успешная авторизация
deactivate Frontend

== Выбор партии ==

User -> Frontend : Просмотр списка партий
activate Frontend

Frontend -> Backend : POST /api/batches\n(filter)
activate Backend

Backend -> DB : Получить\nсписок партий
activate DB

DB --> Backend : Список партий
deactivate DB

Backend --> Frontend : JSON с партиями
deactivate Backend

Frontend --> User : Отображение списка партий
deactivate Frontend

== Детальная информация ==

User -> Frontend : Выбор партии
activate Frontend

Frontend -> Backend : GET /api/batches/{id}
activate Backend

Backend -> DB : Получить данные партии,\nMES, SCADA, LIMS
activate DB

DB --> Backend : Детальная информация
deactivate DB

Backend --> Frontend : JSON\nс данными партии
deactivate Backend

Frontend --> User : Отображение деталей
deactivate Frontend

== Формирование отчёта ==

User -> Frontend : Сформировать PDF-отчёт
activate Frontend

Frontend -> Backend : POST /api/report/{id}
activate Backend

Backend -> PDF : Генерация PDF
activate PDF

PDF --> Backend : PDF-документ
deactivate PDF

Backend --> Frontend : PDF-файл
deactivate Backend

Frontend --> User : Просмотр отчёта
deactivate Frontend

@enduml
